내 관심종목

이 페이지는 data/quotes.json을 읽어서 표시합니다. 이 파일은 GitHub Actions가 10분마다 한국투자증권(KIS) API로 직접 갱신하므로 손으로 편집하지 마세요. 관심종목을 추가/삭제하거나 종목명을 바꾸려면 data/watchlist.json의 name/code 값만 수정하면 다음 자동 갱신 때 반영됩니다.

개별 종목(ETF 제외)은 data/watchlist.json의 avg_price에 매입단가를 넣으면, 최고가 또는 매입단가 대비 해당 지수보다 10%p 이상 뒤처질 때 카드에 "매도 검토 권고" 표시가 뜹니다. 이건 알림일 뿐이고 이 페이지·워크플로우는 절대 자동으로 매도 주문을 내지 않습니다.
