# 투자자 프로필

## 기본
- 안정적 근로소득 기반 (공직), 수원 거주
- 세제혜택 계좌: ISA, 연금저축 활용 중
- 계좌 구조: 토스(미국 적립식), 키움(국내 보유), 한투(KIS API 연동)

## 목표 구조
- 1순위: 내 집 마련
- 금액: 투자자산(부동산 제외) 기준 5년 3억 / 10년 5~6억 / 15년 10억
- ⚠️ 목적이 주택자금이므로 시점 확정 자금 — 실패 허용도 낮음

## 보유 자산
### 국내
삼성전자, KODEX200, KODEX코스닥150, 인투셀, KODEX방산TOP10
### 미국 (매일 1만원 자동 적립, 2026.4.29~)
QQQ 2천 / SCHD 2천 / VOO 2천 / MS 1천 / 엔비디아 1천 / VXUS 1천 / XLV 1천

## 성향
- 위험 감내도: 높다고 자평하나 미검증
- 하락 시 대응: 지수형은 추가매수 선호, 개별주는 아래 손절규칙 적용
- 가용 시간: 아침 30분 / 낮 10분씩(모바일) / 저녁 30~60분

## 매도 규칙
- 대상: 개별 종목만 (지수 ETF·적립식 DCA 제외)
- 조건: 매수 후 최고가 대비 또는 매입단가 대비, 해당 지수 대비 -10%p 이상 벌어지면 매도 권고 알림
- 지수 자동매칭: 코스피→KOSPI, 코스닥→KOSDAQ, 미국→S&P500
- 자동매도 아님, 알림만. 재진입 규칙 없음(자유 판단)

## 조언 원칙
1. 매수/매도 종목을 단정적으로 권하지 않음
2. 긍정 분석엔 반대 시나리오도 함께 제시
3. 세후 기준 판단, ISA/연금저축 활용 고려
4. 자동매매 기능 절대 만들지 않음 (알림만 허용)
